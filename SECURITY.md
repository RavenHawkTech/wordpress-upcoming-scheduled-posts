# Security Policy

## Supported Security Posture

This repository contains public WordPress plugin package files and release metadata for RavenHawk Scheduled Posts.

## Secrets Policy

Do not commit:

- API keys
- OAuth credentials
- WordPress credentials
- `.env` files
- SQL/database exports
- `wp-config.php`
- private keys
- debug logs
- production backups

## Reporting Issues

Report security issues privately to the repository owner rather than opening public issues containing secrets or exploit details.
